# Gesture-Based Web Instrument - Vision

**Learn, play and jam, with an accessible instrument that fits your movement.**

The Gesture-based Web Instrument is a browser-based musical instrument played with body gestures instead of other controllers. The user's webcam is analysed in real time with MediaPipe, and head or hand movements control the pitch, volume and other parameters of a note. The base product consists of a main page with a grid of cells played through MediaPipe gestures and a settings page. On top of that base we propose additional features: calibration page, learning exercises and network jam rooms.


## Product Vision Statement

**For** people who want to learn music and play with others
**Who** can’t get, or can’t play, a common physical instrument,
**The** Gesture-based Web Instrument **is** a web-based musical instrument for learning and playing.
**That** adapts to each person’s movement, so they can learn step by step and play online, using only a browser and a webcam.
**Unlike** mouse, touch or keyboard-driven virtual instruments, which assume fine hand control,
**Our product** uses gestures tailored to each individual, so even a small movement reaches every note.
